# Website Cooperativa RAJA

Teknologi: React, Vite, Tailwind CSS

## Cara Install

```bash
npm install
```

## Cara Run

```bash
npm run dev
```

## Cara Build

```bash
npm run build
```

## Deploy ke Vercel

1. Push project ke GitHub
2. Import repository di Vercel
3. Vercel akan otomatis mendeteksi settings dari package.json
4. Deploy selesai!

## Struktur Project
